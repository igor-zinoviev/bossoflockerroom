# gear-hunt — пошук спорядження на Temu (Чорногора, 22.12.2026)

Той самий принцип, що `kinship-toolkit/browser/*.js`: Playwright-скрипт, запускається
**локально** на вашому ПК/Mac, не в хмарній Claude-сесії — там Temu технічно недосяжний
(DNS-блок на WebFetch + класифікатор безпеки забороняє headless-браузер проти шопінг-сайтів
у sandbox). Тут це просто ваш звичайний браузер з вашої IP.

## Запуск

```bash
npm install playwright   # раз, якщо ще нема
node gear-hunt/temu-search.js
```

Відкриється видиме вікно Chromium (headed — менший шанс бот-детекту), скрипт пройде по 11
категоріях з `QUERIES` у файлі, роздрукує в консоль усі лінки, де поруч із текстом є ціна,
і збереже `temu-results-YYYY-MM-DD.json`.

## Що робити з результатом

Скиньте JSON (або просто консольний вивід) Claude в чаті — лише тоді можлива чесна жорстка
оцінка "топ / не варто", бо тільки тоді є реальні URL/ціни/тексти, а не вигадані орієнтири.

## Якщо Temu показав CAPTCHA

Скрипт зупиняється і каже прямо — пройдіть перевірку вручну в тому ж вікні, потім перезапустіть.
Жодного обходу захисту тут немає, як і в решті тулкіта (див. `kinship-toolkit/README.md`,
розділ "Чого цей набір свідомо НЕ робить").

## Якщо скрипт нічого не знаходить / знаходить сміття

Клас-неймінг Temu хешований і регулярно змінюється — я (Claude) не мав живого доступу побачити
поточний DOM під час написання, тож скрипт шукає узагальнено (будь-який `<a>` з ціною в тексті
поруч), а не жорстко прописаними CSS-класами. Якщо це дає шум/пропуски — скажіть що бачите в
консолі, підправлю евристику під актуальний вигляд сторінки.
