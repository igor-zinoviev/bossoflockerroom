# Робочий процес і економія токенів

1. **Реєстри — єдине джерело істини.** `person/artifact/claims/relationship/search-log` + `research-state.md`.
   У новій сесії/для нового агента завантажуйте лише `research-state.md` і підсумок `python -m kin validate`, а не історію чату.
2. **Спершу сніпети, потім текст.** `kin.ia_fts.search` повертає ≤260 символів на хіт; повний OCR (`text_for`) — тільки для
   2–5 відібраних документів; з нього в контекст потрапляють лише вікна навколо ключового слова (`contexts`).
3. **Все кешується** (`Fetcher(cache_dir=...)`): повторний запуск не б'є по мережі й не витрачає токени на повтор.
4. **Вивід — один рядок на результат + рядок `ПІДСУМОК`.** Великі відповіді пишіть у файл, у чат — тільки висновок.
5. **Кожен пошук — рядок у `search-log`**, включно з негативними та заблокованими. Перед новим пошуком — `grep` по логу.
6. **Паралельно — різні хости, послідовно — один хост.** Це вже закладено в `Fetcher` (блокування на хост + пауза).
7. **Каталог один раз → локальний пошук** (`kin avr`): 37 запитів замість сотень «зондувальних».
8. **Порядок конвеєра:** анкета → гіпотези (хто/де/коли) → пошук пулами (IA FTS, AVR, Geneteka, каталог FS, KnigiPamyati тощо) →
   `entity.cluster` для тезок → `kin validate` → `kin gedcom` → звіт. Висновок «доведено» лише при ≥2 незалежних групах.
9. **Блокування ≠ кінець.** Зафіксуйте (`HostBlocked`/403), знайдіть дзеркало або альтернативний індекс, а де потрібен вхід —
   попросіть людину зайти самій і дати шифр/скріншот. Не обходьте захист.
10. **Приватність.** Живих людей у звітах приховуйте, паролі й `storageState` тримайте поза репозиторієм, не завантажуйте
    документи/ДНК на сторонні сервіси без явної згоди власника.

## Як друзям почати
Скопіюйте каталог `kinship-toolkit`, створіть `case/` із двома CSV за схемою навички, заповніть `person-register.csv`
(мінімум: `person_id, preferred_label, living_status, birth_estimate, death_estimate, places`) та `relationship-register.csv`
(`relationship_id, person_a_id, relationship_type, person_b_id, status, independence_groups`), запустіть `python -m kin validate case`.
